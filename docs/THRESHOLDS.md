# 解码门限实测 · Measured decoding thresholds

## 方法

每条链路先生成一段**无噪声的合成基带**，格式与真实下行一致：CCSDS 链路是 CADU、RS(255,223) 双基、I=4 交织、CCSDS 加扰、K=7 卷积码和 RRC 成形（MetOp 为 3/4 删余）；FY-2 是完整的 S-VISSR 帧，包括 PN 前导、12 个扇区、CRC-16、填充区和 NRZ-M。信号带少量载波频偏、随机载波相位和随机符号定时偏移。

然后按 Es/N0 逐档加入白噪声。原信号本身不含噪声，所以每一档的 Es/N0 是精确值，不需要从频谱估计。每一档生成一份 16 位 IQ 文件，同一份文件分别交给两个解码器：
- NadirStation：`tools/threshold_probe.cpp`，内部就是程序本身的解码器；
- 一个逐级硬判决的传统解码方案。

**成功率**：数通过完整性校验的帧。
- CCSDS 链路：NadirStation 数 Reed-Solomon 校验通过的帧；传统方案的输出逐帧与发送内容比对，数据完全一致才算。
- S-VISSR：数帧被接受的次数，判据是 DOC 扇区标识正确，并且至少 4 个扇区标识正确（每个最多错 2 位）。传统方案的帧用这条判据在输出里数；NadirStation 用程序自己的接受计数。
- 两个解码器各自除以自己在无噪声文件上的帧数。

**门限**：成功率跌破 99% 时的 Es/N0，在相邻两档之间线性插值。数值越低，说明能解越弱的信号。

## 结果

| 链路 | NadirStation 门限 | 传统硬判决方案门限 | 差值 |
|---|---|---|---|
| GK-2A LRIT | -1.5 dB | 1.6 dB | +3.2 dB |
| ELEKTRO-L LRIT | -1.6 dB | 1.4 dB | +2.9 dB |
| MetOp AHRPT | 4.5 dB | 5.0 dB | +0.5 dB |
| GK-2A HRIT | 1.5 dB | 3.7 dB | +2.2 dB |
| ELEKTRO-L HRIT | 1.5 dB | 2.9 dB | +1.4 dB |
| FY-2G S-VISSR | -7.6 dB | 4.7 dB | +12.3 dB |

MetOp AHRPT 的合成流按真实下行的格式生成：3/4 删余，G2 输出取反。用同一台接收机录下的真实 MetOp 录音核对过，两个解码器都能解这种格式。

`≤` 表示测到最低一档时成功率仍在 99% 以上，真实门限只会更低。
